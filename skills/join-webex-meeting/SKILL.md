# Join a Webex meeting

This is a browser task on the bot's computer. Do not use the Webex chat tools to join a call.

## Open the meeting

1. Open the link the user gave you. Webex links look like `https://meet.webex.com/...`, `https://<site>.webex.com/meet/...`, or `https://<site>.webex.com/wbxmjs/joinservice/...`.
2. Stay in the browser. If the page offers the desktop app, download, or "Open Webex", choose **Join from this browser**, **Use web app**, or **Join from browser**.
3. If the page asks the computer to sign in to Webex, hand the screen to the user and wait. One sign-in is enough; the browser keeps the session.
4. Allow the microphone and camera prompts.

## Waiting room

A lobby or waiting room means the join worked. Tell the user you are in the waiting room and stay there until the host admits you or the user tells you to leave. Do not keep clicking around.

## While you are in the call

You can see the screen. You cannot hear the meeting. If captions or a transcript panel are visible, read those when the user asks. Do not claim you heard something that is not on the screen.

Leave when the user asks you to leave. If the site says browser join or guest join is turned off, say that and stop.
